# 29 中央灯塔岛：独立造型拆解与保护范围

本次直接查看 `ref/1342.png` 和 `captures/validation_runs/lantern-lighting-28h-20260908T163354Z-e69c09f62fc547389d39adbbd0011225/images/reference-beam-only.png`，读取 `blender/model_lantern_islands_20l.py`、20l模型报告与 `round-20l-path-independent-review.md`。只做场景审查；没有运行 Blender/Godot，没有修改模型或生产。以下是下一轮验收标准，不是29资产通过结论。全部20参考及原开场范围保持。

## 参考与当前差异

参考中央近岛是多块相互咬合的岩体：塔下平台较小，岛顶两侧有不等高肩峰；深色竖裂面、斜裂面与短岩脊交替，轮廓有突出与回凹。贴水基脚由几组扁长、不等大礁石形成，部分高出水面的小尖峰打断岸线。草主要留在上部台地及岩肩间，形状受岩体制约。

当前中央 D 有两段显眼的连续灰色环墙，绿盖形成宽而平顺的斜带，侧壁高度变化与岩面变化不足，基脚只在少数位置出现小碎块。改变三角材质或在外围均匀加一圈石头，仍会保留这个主体轮廓问题。当前岛塔也位于参考中央岛更右的位置；本轮保留世界位置的造型工作不能宣称已经解决完整构图、尺度与地理布局。

## 有限且具体的29造型标准

1. 从参考机位可见的海侧长墙着手，拆出至少两种不同尺度的断裂段：一个宽重承重崖块、一个较窄倾斜肩块，中间有可读的凹槽。数量是作者组织构图的建议，不是以件数验收。
2. 至少一处岩肩真实上穿现有绿盖的边缘，使顶部轮廓与草岩交界同时变化；其他位置降低为短斜坡或平台，不形成等高齿冠。保留塔台和屋台的安定落脚关系。
3. 外围礁石按两三组潮间带簇组织，选一组扁长低礁、一组较高破裂礁、一组细小过渡块。大礁底部入水或埋入主岩，不悬浮、不形成重复八边柱环。保留组间水道与负空间。
4. 低多边形面应表达一块岩石的共同断裂方向与大体积。允许明确三角切面，不能以密集随机碎三角、统一放射扇面或同一模板等距重复作为细节。
5. 夜间应仍可读出大块暗崖与少量朝月亮的亮面；不以整块提高灰度代替造型。白昼或较亮侧景应证明新凹槽不是材质涂黑。
6. 从 D 的侧面/背面，以及共享 C 实例的相机检查，新体块不能只在参考面堆出外壳。参考并未证明这些侧背面的原始形状，设计关系需标为合理设计。

## 几何保护与新增碰撞检查

20l C 使用 `sx=.56, sy=.54, plateau=14, variant=2`；当前 D 是共享 C 的旋转实例，因此必须在两实例实际变换后检查，不只看 C 原点模型。

- **实际路径优先**：保留 `island_c terrain fitted keeper paths` 的全部真实顶点/拓扑和对应地表支承面。20l独立记录为259个路径上表面三角，最大坡度9.65°，1254个抽样位置的路径/地表高度差约0.045m；这些是旧证据，29必须以实际保存/导出的路径比较确认才能继承。
- **排除区按面定义**：新增礁肩或修改主岩不能侵入实际路径上表面投影及其通行上方空间。仅排除中心线点不够；用路径三角合并投影或完整路径网格做连续范围检查。路缘外的保护宽度若额外扩展，应记录设计数值，不能把经验宽度说成旧工程事实。
- **塔台**：源 `pads` 的塔中心为 Blender XY `(1,1)`，原作者平台半宽6.3m；高度函数最后保护实际基础周围4.2m半宽。用导入后19h基础真实包围投影验证承托面保持，不能只验证中心高度。塔台实际地形、灯塔位置及旋转应保持。
- **屋台**：源屋台为 Blender XY `(-12,-14)`，半宽 `(3.2,5.3)`，角度 `-.15`。保留实际房屋基础投影及入口、既有连接路径附近高度；不要根据未旋转矩形误排除。
- **树木**：从本次实际冻结装配读取 C/D 树实例变换和底部包围体。新增岩肩不得吞没树干、在树根下形成悬空；若既有落点本身存在问题，应报告，不把不变坐标当作支承合格。
- **体块与海面**：原生新增岩体需闭合、有正体积且无退化面；相邻块可以有明确埋合，但检查可见交接处的裂缝、共面闪烁、细薄穿刺。潮间带礁底需与海面及主岩有设计关系，不能只以单件闭合证明场景合理。
- **实际运行碰撞**：若此轮替换 C GLB，更新/生成该候选的岛体碰撞，核对实际导入网格与碰撞来源哈希。至少做既有路径、建筑基础/门口及新增岸礁的目标射线；不重复无关的26b主岸道路全套验证。共享 C/D 都要用实际世界变换验证。
- **保留范围**：A/B、19h灯塔、既有房屋、26b主岸/道路、27云水与28h光束无需随造型变动；保存29新目录，保留20l和所有失败证据。不得运行整体世界生成器或覆盖手工权威东部岩体。
