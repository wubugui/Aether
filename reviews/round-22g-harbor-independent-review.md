## 船旧位置与新泊位

四船各 138 个实际导出、世界 Y≤.12 的低位顶点，同时回查旧 22a 与新 22g 位置。射线明确排除 SeaCollision 后再查 mask4 原地形，全部都有真实 Terrain hit，没有用 null 或水面 0 替代海床。

旧位置四船分别有 48/49/49/48 个负净空，最小约 -.989 m。这说明旧放置确实有被查询低位顶点进入原地形，22a 时保留的浅滩风险现有测量支持，不能继续说旧船未搁浅。新位置各 138 点全为正，最小分别 .577184/.575658/.576085/.583654 m；支持本次外移修复了这些实际顶点的地形穿入。顶点之间船面、动态浮力、水位变化和系泊运动仍未验证。

[船首至平台独立距离](E:/FeiTing/reviews/round-22g-boat-landing-independent-distance.json) 使用同版实际完整船/横平台三角，在 pier 局部坐标施加船 (3.9,.02,4.4)、相对旋转 .08，以及平台 Z=11 的装配。船最前缘 Z=7.935489，距名义平台开始 Z=8 仅 .064511 m；不能说沿轴还有很宽的余量。

进一步检查实际所有材质平台几何，最前端某些构件到 Z=7.9，但它们不占船首所处的 X/Y。完整两网格没有三角包围盒重叠对；最近实际表面距离约 .254511 m，点对约为 (4.103429,1.415532,7.935489) 与 (4.103429,1.415532,8.190000)，并非误用船/平台整体包围盒相交来判断穿透。此处是静态几何间距，原生远世界坐标存在亚毫米舍入；不保证摆动、转舵或缆绳情况下仍有安全间距。

## 灯位与临时植被

每图有 54 盏港岸灯：23 屋旁、16 码头、15 石阶旁。独立用实际实例变换重算局部灯芯 (.84,2.44,0)，与记录全局光源位置最大差约 .161 mm。日间能量 0、夜间约 1.8，实图暖色受光也成立。岛塔的四盏环境灯另计，不混入 54。

屋区 vegetation_adjustments 仍为空，但路径清理实际在临时 MultiMesh 副本移除两项：oak_-4_-4 的 index 9（约 [-2512.620,14.346,-2523.574]），rock_-4_-4 的 index 5（约 [-2657.117,3.716,-2674.663]）。这次不能套用 22a 的全部清理为零。它们是临时路径避让，不是生产资源删除；侧车 production_modified=false，World 和原生灯塔 SHA 保持记录基底。此处未另扫所有磁盘文件。
