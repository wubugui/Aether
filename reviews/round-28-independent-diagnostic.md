# Round 28 independent optical diagnostic

Independent reviewer inspected the actual frozen 28b shader/adapter, 28c and 28d diagnostics, native asset builder and actual runtime logs. No GPU or Blender processes were launched by this reviewer and no implementation was changed.

Confirmed failure: the Compatibility renderer's unshaded path uses ALBEDO as final RGB and does not add EMISSION. The 28a/b shader sets ALBEDO to zero and places all beam color in EMISSION, so its additive color output is black even when geometry and density exist. This is explicit in the exact version's [Godot 4.5.1-stable GLES3 source](https://raw.githubusercontent.com/godotengine/godot/4.5.1-stable/drivers/gles3/shaders/scene.glsl), lines 2134–2144. It is an incorrect material output for this renderer, not evidence of a Godot geometry loading failure.

The actual 28d GPU experiment corroborates the source: debug 5 switches color to ALBEDO with fixed alpha and visibly renders broad orange cones from all four lamp positions, with source halos. Debug 1 remains EMISSION only. Relative to normal, debug 5 changes 195,880 pixels, of which 195,623 exceed an absolute RGB difference of 10; debug 1 changes only 732 pixels and 151 exceed 10. These sparse differences are not readable optical fields and should not be interpreted as an effective beam. 28d logs independently record eight visible MeshInstance3D overrides on layer 1 with the expected positions; the runtime count assertion passed. 28c layers similarly produce only 381–690 changed pixels and are not valid density diagnosis until their output color is corrected.

Evidence is in `round-28-independent-diagnostic.json`, generated by the adjacent Python script directly decoding saved PNGs. Directly viewed the actual 28c debug 1 and 28d debug 5 originals. All comparisons preserve original output images.

The minimally justified next change is to move the existing unshaded beam color into ALBEDO and clear EMISSION, preserving actual volume geometry and integration first. Rendering presence does not accept beam shape, brightness, occlusion, weather behavior, or reference fidelity. The debug 5 hard orange wedges are explicitly diagnostic, not production art. The original 1342 reference remains substantially richer in water glints, cloudy sky, jagged islands and village detail.
