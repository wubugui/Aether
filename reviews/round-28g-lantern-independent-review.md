Thus sparse full-frame differences cannot be attributed confidently to improved core transmission; selected receivers show no meaningful brightening. This rejects the proposed visual repair for the tested state, without claiming that the core can never cast a shadow in any other renderer/camera/light configuration.

The reference beam is more readable across the sea, and the side view shows coherent fixed directions with the improved28f axial fade. The detached orange far-end pools from28e do not return. The lamp interior and near receivers do not receive a corresponding native-light improvement; this is an additive volume-color change. Beam-boost inherits core-shadow OFF in this diagnostic, so the exact evaluated state is documented rather than silently calling it a pure baseline-plus-energy image.

Retain the rebased finite-frustum integration and improved distance profile, and use the stronger beam as a local visual basis. There is no evidence-based need to carry the core-shadow experiment into the retained design solely to cure receiver darkness. The lamp should still become a stronger warm focal point relative to the original1342 scene; broader sky, water, island geometry, dense coast village and warm reflection gaps remain. Dynamic weather, continuous-flight and complete camera/light-space occlusion acceptance are not supplied by these three static cameras.
