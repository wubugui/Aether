## 按视觉贡献排序的六项返工

### 1. 前景：现在是碎三角山坡，缺少参考的宽岩壁、草顶和深沟

开场主要问题集中在 **x≈1080–1672 / y≈625–941**。参考右前景是宽灰岩壁、倾斜但连续的草顶、深色沟腹相互遮挡；09n 的 **x≈1180–1450 / y≈690–890** 则由许多尖顶和交替灰绿三角构成，缺少参考 **x≈1180–1420 / y≈750–865** 那几块具有分量的灰岩正面。最高点约 **(1398,624)** 已接近，应保留定位，主要改它下面的厚肩和岩壁，而不是继续移动整个山组。

权威侧图 **x≈575–1130 / y≈355–720** 有了真实前后厚度，但依然像连续排列的灰色尖楔。背图 **x≈620–1110 / y≈375–650** 变成有体积的岩坡，改善成立；外围 **x≈430–1210 / y≈650–940** 仍有长细三角、突兀的硬色界与尖角，山脚缺少有方向的沟谷收口。这里仅凭图像判断可见表面，不能把色界直接称作物理裂缝。

当前 `make_terraced_cliff` 的三角高度场使用没有内部边约束的 CDT，再在大三角质心按独立正弦值增减高度。这样确实能增加起伏，却不能确保一条山肩或排水沟连续通过多个断面；增加的面容易成为碎斑。下一版应明确每块的主肩线、谷底线和前后断面，约束其连接关系，然后调整灰岩裸露区域。不要继续用无方向的小起伏取代主要形体。

前景固定 ROI 的平均 RGB 当前 **(139.1,147.0,119.7)**，参考 **(126.8,133.7,112.7)**，红绿仍高约 12–13。先恢复深沟和灰岩覆盖面积，再分材质调色；全局压暗草地会损伤已偏暗的中景区域。

### 2. 中景地理：仍像稀疏的大地图，湖湾、丘脊和聚落尺度未恢复

参考 **x≈60–700 / y≈465–675** 和 **x≈850–1400 / y≈525–745** 有连续的小丘、浅滩、半岛、湖岛、树林和聚落层次。09n 仍以大块黄浅草坡、少数狭长水道和间隔较大的物件为主。当前城堡周围的大片空地与笔直道路也使空间显得过于整齐。

重点沿 **x≈380–695 / y≈680–905** 校准西海岸的突出岸角、内凹浅湾、浅青水区和窄沙岸；不能仅使一条折线经过几个参考点。中央水系 **x≈840–1330 / y≈520–655** 的曲折层级、宽窄交替和陆地穿插仍不足。左下岛当前约 **x≈185–385 / y≈884–941**，比参考约 **x≈235–380 / y≈887–941** 明显向左扩展。

新树簇有帮助，但不能以继续增加等尺寸树点解决地形缺失。应先确定中景丘脊与湖岸的高程、遮挡，再按参考的区域密度分组布置。固定小区域 **(880,674)–(940,704)** 的平均 RGB 当前 **(185.9,185.7,137.2)**，参考 **(193.1,193.9,143.8)**，该处反而偏暗约 7–8；“整图发黄”与每块草地需要怎样调亮不是同一问题。

### 3. 雪山：峰点接近，但大形仍是重复尖锥和少数巨大壁面

保留主峰约 **(1235,307)**、次峰约 **(1145,325)**，重点编辑顶点下方 30–100 px 的肩部，以及 **x≈1090–1300 / y≈395–515** 的前排脊谷。参考并非每座山都有一个孤立尖锥；存在宽厚岩肩、斜长雪脊、遮挡后的副峰和深浅不同的蓝紫灰谷面。

09n 正面 **x≈1210–1405 / y≈310–445** 仍有过于锐利的针峰与宽白斜面。权威背图 **x≈790–1170 / y≈355–745** 中，几个高大近三角形壁面仍然主导，底部也是宽整的斜裙。真实山鞍和局部新顶点没有使这些主壁充分转折。

下一版先分别重做主峰肩线、侧向支脊和下部谷口，保留现有山鞍，不再靠降低山鞍或增加小尖点制造复杂度。雪山 ROI 当前均值 **(178.3,200.9,208.8)**，参考 **(184.2,202.2,214.2)**；当前数值改善不能证明雪面和阴影的分区已经正确。需在几何稳定后分别校正暖白雪面、蓝紫灰谷壁和雾的影响。

### 4. 左台地：仍是整圈挤出的块体

当前可见台地约 **x≈113–272 / y≈537–607**，整齐的平顶、近乎等高的垂直墙和薄脚裙使它像摆在地上的块状道具。参考主要地貌范围约 **x≈65–265 / y≈525–626**，左侧展得更宽，灰壁向下展开并接入不规则脚坡，顶部也不是一个小圆帽。

本版 mesa 单独调用 `_make_mesa`，这一点成立；但其主要崖圈仍从 cap 扩出约 1.04–1.06 倍、整体下降约 20–22 m，所以同高墙带的原因仍实际存在。为这个资产单独绘制不同侧面的侵蚀沟、壁脚和顶缘；扩大真实横向地貌而非拉长统一裙边。09d 直接贴海岸的双层积木已经修正，不继续重复该旧缺陷。

### 5. 飞艇：总包围范围接近，但部件比例与线条不一致

整体范围约 **(663,359)–(899,600)** 已接近参考，不建议再统一缩放或大幅移位。气囊仍有较整齐的面带和偏扁的下缘，参考中段绑带沿鼓起布面形成更明显的弧线。艇舱偏方、甲板和船舷轮廓过于规整，参考船体有更复杂的上下收束、船艏起伏和木构细节；当前灯笼、货物和吊索也显得过于简化。

### 6. 云群与 UI：坐标相近，形状和材质表现仍未恢复

四个主要云群位置大致正确，但几何读感仍是几个多面球堆在平底上。参考右上云 **x≈985–1310 / y≈120–214** 顶部更不规则、底部层次更丰富；中央云 **x≈643–936 / y≈232–309** 是展开的柔和云体，当前球团轮廓和长平底更醒目。应改云团的真实交叠和薄厚、明暗朝向，不能只整体改白。
