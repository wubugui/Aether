# 高岸候选原生场景

从工作区根目录运行 `run-highcoast-candidate.cmd` 可进入本候选的既有飞行控制；`open-highcoast-candidate.cmd` 指向候选 World 编辑场景。正式 `run-3d.cmd` 仍指向原生产场景。

World36c.tscn 保留208个地形实例与773个散布组，其中14个地形块来自 `captures/highcoast_study_36b/` 的独立 Blender 模型。Game36c.tscn 同时保留此前港岸、岛屿等候选区域，并使用既有飞行脚本和35c空间天气。新候选使用自己的进度文件，不覆盖原航行进度。

36b高岸装配阶段为54800个散布实例；随后的港路避让明确移除2棵松树和1块岩石，故完整候选为54797。新松树组补齐原有逐实例编辑脚本与prefab引用。保存场景没有打包运行时临时散布碰撞。

36c仅修复36b生成场景的资源引用语法；没有改几何、材质或变换。36g在新Godot进程中成功重开World/Game，核对14块网格/碰撞及散布辅助，并用既有测试输入执行240个物理帧、产生约88.96米的起终点位移，输出两张实际GPU图。该短程位于Z约-1910的港湾，在新高岸编辑域之外；不是新65点高岸航路的物理回放。验证脚本在正常初始化后冻结World流式处理，候选保存场景本身没有保存这个验证冻结状态。

编辑启动脚本的命令目标已核对，但尚未通过真实编辑器界面验证Extract按钮、编辑后重存或常规GLB自动重导入。captures目录仍有.gdignore；地形场景使用保存的内嵌ArrayMesh，Blender/GLB源作为独立可编辑制作源保留。

这仍是未通过全部参考美术要求的候选。河谷与前方视野改善；长直岸边、大草坡、云板/云块、水面和其他区域/天气/内景继续制作。36b、36c包装预检、36d断言失败均保留，不能把36g局部重开通过当作整世界完成。
