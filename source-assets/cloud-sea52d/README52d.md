# CloudSea52d：仅一个代表云脊，待单件五面评形

52c五面已全部实看，明确失败：窄Gaussian高度场形成尖雪山/火山锥，共底仍像扁盘，停止该路线。52、52b、52c源及失败图完整保留，未集成。

52d只有一个代表主脊，暂不扩变体。使用8个强弱不同、偏位、拉伸且轻微雕变的闭合控制体：一个胖圆主冠、一个偏置次冠、大小不同的侧肩、低尾和错高圆腹。只对这一条主脊做局部体积并合，没有整tile并合，也没有独立公共底板。生成后轻柔处理局部接缝，再形成克制、不规则三角面。是否真正像云，须由下一轮实图判断。

`cloud_sea52d.blend` 含1个最终件及8个可编辑隐藏控制体；`cloud_sea_52d_0.glb` 是1个mesh的独立导出。最终1100三角/552顶点，尺寸约745×467×386m，局部z为-30.46至355.37m，若未来放在原Y700锚点，顶为1055.37m。本稿为保留圆冠圆腹未把厚度硬压回320m设计建议，整体布局/覆盖率仍未设计或验收。

`geometry52d.json` 是重开源读回；边界0、非流形0、单连通正体积。`surface-integrity52d.json` 记录最终非邻接三角自交0、零面积三角0。GLB有POSITION/NORMAL/COLOR_0，沿用BlenderXYZ到Godot `(x,z,-y)`。材质及顶点色完全沿用46原式，未修改生产45/47材质。`protected-sources.json` 核对旧46、权威悬崖及52/52b/52c源前后SHA未变。

父任务安排图形窗口后运行：

`python source-assets/cloud-sea52d/run_preview52d.py`

仅渲染单件五面，同46灯光；为看清单件形态，正交宽度改为1000m，目标点为(0,0,140)。视角方向基本沿用旧五面，实际投影逐面检查3%留边。支持 `--white`，官方Blender4.5.14/CPU4线程，完整日志、退出码、输入输出SHA写独立cloud-evidence目录。不保存预览对源的临时修改。

当前未执行预览、未启动Godot、未集成、未扩3变体。下步重点看主冠是否胖圆、次冠与侧肩是否形成真实鞍隙、底部是否圆腹而非共底，及是否存在重复等球串的最终外观。
