# CloudSea52f：三种新增低云组合，等待实际多面与世界审查

这批扩展独立保存在 `source-assets/cloud-sea52f/variants/`。父目录内已审的单鞍体、双低体源和脚本均冻结且未改变，可分别恢复。父任务与制作者已实看双体v0五面 `cloudsea52f-two-body-source-v0-20261001T062157Z-fze5esem`：双弧与留白可作为覆盖修复实验，但下腹圆盘列、上方扁石与球列仍需持续改进，不是最终云形通过。

## 原生源与三种布置

`cloud_sea52f_variants.blend` 共15个闭合成品、216个隐藏可编辑控制体。9个52e冠体资源和已审v0两低体逐网格保留，只新增v1/v2四个低体及89个控制体。旧源的全部138个网格指纹一致，检查包含顶点、拓扑、色属性、物体矩阵与材质名称。

三种安排分别是：

- v0：已审的横向分叉鞍体＋沿尾部转弯的低漂流体，不作重塑
- v1：偏斜主脊、中段较长低颈和向正Y伸出的分叉；另一件从左侧低端经较高后弧返回右侧。八个主控制体与七个主控制体组成不等长路径，肩部成组爬升
- v2：反向折弯主脊、向左后侧折出的分叉；另一件为偏心后弧、内侧分叉与向右后折回的尾端。低谷围合与v0/v1不同

新四件不是v0旋转/缩放复制。控制体路径、数量、半径、顶底高度及单体倾斜角分别布置。中大体增加厚度与倾斜，稍收下部轮廓；小体积仍集中在肩/谷/端缘，未均匀散点。原52e上冠与v0问题形状未改，以保留可归因的覆盖实验。新形状是否足以减少圆盘/条带感仍待实际图像判断。

低体在原700m根下，局部最低下腹约476m，不能假定低空飞行路线通过。材质取原Cloud46；顶点色仍为原高度公式，不调曝光、亮度、其他云层或环境。控制体保存在各自Editable集合，源内三套安排共用原点以便分别导出，编辑时按variant隔离集合。

## 导出与未来集成入口

每个N=0/1/2都有：

- `cloud_sea_52f_N.glb`：原52e对应三件＋52f对应两低体，共5mesh，供组合源审查
- `cloud_sea_52f_additions_N.glb`：仅两新增低体，共2mesh，供优先的加法集成

建议未来集成只使用additions文件，保留Game52e原75冠体节点、网格与路径；在原25根下添加对应两体，总计50个新MeshInstance3D。每根variant索引沿用原分配，根位置/朝向/尺度、生产材质与原节点所有权等保持不变。此目录没有运行集成脚本或保存任何世界场景。

新增节点名为 `CloudSea52f_vN_low_saddle`、`CloudSea52f_vN_low_drift`。六份GLB不带相机/灯光，节点为单位变换。Blender `(x,y,z)` → glTF/Godot `(x,z,-y)`，实际POSITION bounds逐项核验；包含POSITION/NORMAL/COLOR_0。

## 重新打开与真实覆盖结果

`geometry52f-variants.json` 从重新打开新.blend读回：15个成品各自单连通、闭合、正体积，边界/非流形/零面积/非相邻自交均0。旧138网格指纹全部相同。局部自交检查不等于多体重叠处没有可见接缝，更不代表下方云顶/飞行通过。

`analyze_coverage52f_variants.py` 读取六个新增低体的实际GLB三角，把三套分别放在原variant索引对应的25个根下；v0/v1/v2根数为10/10/5。采用原52e诊断相同的内部3.45km方格、10m采样及原1216机位，计算真实三角并集，不填AABB/凸包。

| 诊断 | 原52e | 重复v0双体的尺寸试验 | 三变体实际分配 |
|---|---:|---:|---:|
| 内部俯视覆盖 | 35.24% | 76.99% | 79.49% |
| 最大连通空白采样面积 | 7.708km² | 0.7953km² | 0.6705km² |
| 1216正面下半屏覆盖 | 54.47% | 94.89% | 96.82% |
| 1216侧面下半屏覆盖 | 66.28% | 97.17% | 98.44% |
| 1216背面下半屏覆盖 | 59.02% | 78.70% | 82.23% |

三变体进入原70–85%的覆盖试验范围，同时保留有意空谷；背面仍可能出现过大的贯通谷。完整根变换、各输入SHA及指标在 `coverage/coverage-report52f-variants.json`。这些诊断不含其他世界对象、真实光照、材质或碰撞，不能作为视觉通过。

## 父任务逐variant五面入口

```sh
python source-assets/cloud-sea52f/variants/run_preview_variants52f.py --variant 1
python source-assets/cloud-sea52f/variants/run_preview_variants52f.py --variant 2
```

每次一套五面；v0几何与已审源逐项一致，可直接引用既有五面而不重复。也支持 `--variant 0`、`--pair`（只看低体）、`--isolated`（仅drift）与 `--white`。2250m正交宽度、同机位/灯光、900×640、20 samples CPU4线程，预览不保存源。十五个机位只读预检通过，最小边距3.07%。包装器将输入/输出SHA、日志、退出码、保护源SHA和PNG清单写入独立cloud-evidence目录。

本任务未启动GUI/Cycles/Godot，未保存世界、未改项目默认、未运行世界生成器，也未提交/推送。Game52e SHA保持 `5abbabf7487766412592f0b93ccd12c01e7bbb70f28e96ffd829e7ae78919079`。实际图像审查后，才由父任务决定是否进入有限世界试验；完整GOAL继续，visual_acceptance保持false。
