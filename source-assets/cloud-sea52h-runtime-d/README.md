## Four actual frames and strict restoration

1. A0 is the untouched original main mesh state and is saved as its own PNG. One full typed native baseline is saved to A0-native-baseline.bin, plus a compact hash/size summary.

3. D replaces only the ten contracted v0 main mesh resources with the actual 1834-triangle D GLB geometry. An actual GLB ancestor transform is used only if necessary. All native state must equal A0/A unmasked. Every decoded RGBA byte and the PNG bytes must equal A. One pixel or alpha-channel difference fails. The old52g A/A2 failure is never relabeled or rewritten.

## Actual camera versus closed cloud geometry

For every phase, the actual camera position is tested against each of the ten target meshes' actual world-space triangles. In D, the resource and closed-native-source proof must bind the exact D GLB SHA. The diagnostic records the nearest triangle, closest world-space point and distance, all three nonparallel ray-parity votes, actual world transform and world-triangle-byte digest.

A point within0.025m of the triangle surface is classified as boundary. Otherwise all three odd votes mean inside, all three even votes mean outside; disagreement is ambiguous and fails diagnostic completeness. Boundary/inside results are reported honestly and can coexist with the separate physical collision query being clear. The run does not claim a camera sphere, ship volume or flight corridor is clear. A valid inside diagnosis does not count as visual acceptance.
