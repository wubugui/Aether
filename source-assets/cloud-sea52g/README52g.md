# CloudSea52g v0：上冠大小层级与弯脊原型，等待实际五面

独立目录，未修改52f任何源或保存场景。已实看参考1216、52f世界正/侧/背三图以及52f近侧/近下/475m下腹四图。52f填补空洞已有进展，但等大球/扁石列、厚硬圆盘下腹和近景条带明显存在，覆盖率提升不是形体通过。

## 本次试验的明确边界

只重塑v0三件上冠，原52f v0两低体和61体积控制原样带入。原低体连接、留白和材质行为保留为对照；厚球腹天花板仍未解决。源五面未实际审查前，不扩三变体、不保存世界、不重新渲染任何旧终态。

新源 `cloud_sea52g_prototype.blend` 有5个成品、64个可编辑控制对象。新冠体改为3个闭合截面控制网格，而不是新增球堆。每个截面控制网格包含54圈×40点及两端闭口，原生可编辑；生成方法、截面结点和网格均保留。旧两低体和61控制共63网格的顶点/拓扑/颜色/矩阵/材质名指纹不变。

## 几何构造与比例

- 主脊：名义长740m、截面宽460m、顶350m；偏心圆钝主冠、两个较低副肩、较深的宽鞍口，曲线结点不等距
- 次肩：名义435×310m、顶215m，侧偏弯曲并降低整体量感
- 低尾：名义305×230m、顶120m，缩短并降低，形成第三层级

设计占地目标约5:2:1，实际真实三角投影面积另见 `upper-footprint52g.json`。名义截面宽不是旋转后的轴对齐bounds；主脊因12°转向及侧弯，实际AABB约721×576m。圆钝转折由平滑截面插值和一次曲面细分形成，三处真实侧凹沟与错位肩改变体积轮廓。没有尖锥、公共水平底面或另加球体；是否仍像山体、波浪肋条或硬台必须由实际五面决定。

三新冠成品分别2200/1300/850三角，实际最高345.74/213.41/119.12m。原Cloud46材质与高度顶点色公式沿用，不调曝光/亮度/颜色。

## 校验与失败证据

`geometry52g.json` 从重新打开.blend读取：五成品各自闭合、单连通、正体积，边界/非流形/零面积/非相邻三角自交均0。新冠体含少量长三角：最长边平方除二倍面积大于20的三角数量为主3、肩4、尾2；这是几何质量诊断，不能证明近景条带消失。

第一版尾端插值造成6对自交，源、GLB、脚本、日志和报告保存在 `attempt-a-tail-cap-intersections/`。当前将冠顶变化改为相对腹底厚度缩放，端点处腹底扰动衰减为0；修复后的原生源重新打开通过。旧源未覆写。

GLB：`cloud_sea_52g_upper_v0.glb` 仅三新冠；`cloud_sea_52g_prototype_v0.glb` 三新冠＋两原低体。真实轴映射仍为Blender `(x,y,z)` → Godot `(x,z,-y)`，POSITION bounds逐项核验，包含POSITION/NORMAL/COLOR_0。

## 交父任务的实际五面入口

```sh
python source-assets/cloud-sea52g/run_preview52g.py
python source-assets/cloud-sea52g/run_preview52g.py --isolated
```

默认三新冠＋两旧低体；`--isolated` 只看三新冠，便于识别主副比例、凹沟和潜在等间距肋条；`--pair` 可只看保留低体但通常直接复用旧证据。900×640、同2250m正交宽度/机位/灯光、CPU4线程20samples，预览不保存源。只读五面机位预检通过，最小边距4.07%。本工作未启动GUI、Cycles或Godot。

真实五面通过后才讨论下一轮形体或有限世界试验。总GOAL仍在进行，visual_acceptance保持false。
