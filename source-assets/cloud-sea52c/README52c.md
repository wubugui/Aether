# CloudSea52c：独立源候选，待五面评形

52b五面全部实看，与1216参考再次对照。52b虽然去掉黑缝与环纹，但冠丘合并成宽平台、外壁像软化岩台、下腹近均质碗，判失败。52b和52所有源及实际预览保留。未集成其中任何一稿。

52c不再叠加大范围径向Gaussian。每件的非环状三角控制笼上定义5个偏位、不同高度和占地的主/次冠丘，再定义3个更小侧肩。顶面用窄冠包络取最大值，形成真实高低鞍槽，避免相加后融合成台面。轮廓有不均匀卷肩；底面是3个不同位置/深度的下腹膨隆和之间的上收槽。各件仍是一张连续闭合实体网格，不是独立均匀球堆；主件整体厚度仍约195–320m，没有把全体进一步压薄。

源 `cloud_sea52c.blend` 包含9件最终网格和9个隐藏可编辑控制笼，参数/重建脚本保留。每件920三角（52b为1638），每变体2760三角，希望在真实预览中能读出克制分面；目前不能宣称视觉成功。

## 实际读回

- `geometry52c.json`：每件1连通分量、边界0、非流形0、正体积；每GLB实际3mesh，BlenderXYZ→Godot `(x,z,-y)`，包含POSITION/NORMAL/COLOR_0
- `surface-integrity52c.json`：52c九件非邻接三角相交0、零面积三角0，并保留旧52坏面数据作比较
- `crown-relief52c.json`：按最终三角网格边邻接寻找实际局部高点，再排除45m内重复峰，各件找到7个高点（包括较小侧肩）；顶面连线射线采样，主要冠间的下降约54–122m，小侧肩约6–37m。这是几何起伏证据，不是外观通过或精确天然云形证明
- 三变体组合bounds约1384×1187×366、1318×1193×365、1403×1221×376m，保持原Y700根时顶高1060、1050、1075m
- 材质与顶点色完全沿用46原式，无改曝光、发光或透明度，无改45/47生产材质
