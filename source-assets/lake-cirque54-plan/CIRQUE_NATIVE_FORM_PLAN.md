# Cirque54独立原生详细形体方案

状态：实体设计准备，尚无54新.blend、未改场景。基底必须是已保存验证的53west，SHA256`6ec57b72a831d6fa906a8d866c339909de55c9c42297a038dcd429b18d0c2b18`。保留west的5mesh、碰撞、prefab、源及120项既有落位，不覆盖或合入cirque/east/crown旧失败首稿。

本方案实际重看原1128/1129，并逐张查看本轮10图。主要依据是原1128/1129前视及两张200m接近图，后者清楚暴露当前cirque的单一大面、绿坡和突起尖顶。1275/1276继续记录为明显视觉失败，不能用本局部方案声称解决。

## 1. 当前实体与可复核的判断

`massif_cirque_wall`仍是48实际切过湖内脚的闭合源：692三角，源原点(809.49414,0,-1780)，世界范围约X574.62–1028.89、Y-167–136.55、Z-2096.81–-1445.61。53west全图审计证明cirque和相邻terrain原生资源精确保留，所以51b实际导出的这些坐标仍对应53实体；散布则必须使用53已验证的新位置。

最高点(809.493,136.554,-1780.008)在1128实际相机下投影约(30.55%,44.60%)，在1129约(35.29%,44.99%)，正是本轮画面左中部的低灰绿突起。不能只给它涂白，也不能把它等比抬成高锥。

建议先把它作为**近中景冰蚀山肩**处理，主肩试作点约(790,230,-1930)，预测1128约(32.87%,38.82%)、1129约(37.89%,39.89%)，而不是直接认定它对应参考左中部那座更远、更高的主峰。`projection-options.json`保留A/B/C等不同高度探针。把当前近水脚直接抬到255m或更高，虽能凑近参考某个尖顶像素，却会在不足150m的横向范围内再造陡直大墙；不能为像素锚点牺牲侧背实体。

已逐点核对实际根面：主沟尾原设38m但真实支承57.66m，现改60m；次沟中段原111m低于120.98m根面，现改124m；次沟尾原57m低于79.10m根面，现改83m。原错误猜测和修正分别保留在`control-point-support.json`、`control-point-decisions.json`，不能把埋在旧体内部的白片计作完成雪沟。

所有点位/高度均为待源造型和两原机位复核的作者推断。若实际宽度不足，就降低/北移肩部；不移动原相机，不把计划数值当约束真值。

## 2. 要做出的连续形体

- 北上肩：从约X745–820、Z-2050–-1880形成偏斜、前后厚度不同的宽岩肩。主肩225–235m只作第一试形；顶脊有80–130m长的缓变肩线，避免单个高顶点统领所有三角
- 低鞍：约(795,160,-1810)，连接北肩与前方原山脚。鞍部是有宽度的凹面与背坡，不是两锥之间的窄V切口
- 湖向下肩：约(835,100,-1670)向低岩裙转折，保留至少高肩、雪沟中坡、岸岩裙三层真实体量。大面用不等宽岩肋、两级坡折和局部岩台分开，不能靠随机顶点色假装起伏
- 主下行沟：初始控制链(780,205,-1980)→(840,122,-1850)→(906,60,-1720)，沿实际坡面下行；宽度约35–65m，槽底比两侧岩肋低15–25m，并有宽缓收尾
- 次下行沟：约(752,186,-1900)→(790,124,-1780)→(842,83,-1635)，宽18–35m，走势与主沟错开。不得用固定横剖面比例生成绕山水平雪带
- 背侧另做一条较短侵蚀沟和不对称岩肩，保证从西侧、北侧看仍是完整山体，而不是只修湖向一面

坡折/沟谷通过原生岩体顶点和约束边实现。采用不规则的地质控制点与有意义的长短三角，主要可见岩面边长约18–55m、少量完整大岩板更长；增加拓扑必须带来真实岩肋/凹沟，不把同一平面均匀切碎或逐排重复放样。

## 3. 原生分件建议

保留48的原`rock_body`作为权威下部/水下支承，先与当前保存资源逐三角映射核对。新增分件先按以下职责制作，预估总三角数约3000–4500只作为预算，不作为通过标准：

1. upper_cirque_mass：闭合上肩和背侧主岩体，沿真实干地支承落根
2. lower_rock_shoulders：闭合中下岩肩与不等宽岩肋，覆盖原尖突起的可见上部，衔接低鞍
3. shore_rock_apron：贴合实际干岸的厚岩裙/岩台，不能抬起旧水下脚或造横坝
4. snow_fields：在宽肩及背风凹面形成3–5片相连关系明确的厚雪，保留迎风岩脊；厚度约0.8–2.2m
5. snow_gullies：与真实凹沟相配的两条主雪舌及较短背沟，底面埋入岩面，边缘闭合

雪面不能形成一整块白顶盖；雪线随沟槽、坡折、迎风岩肋变化，不能变成统一高度色带。若旧峰或绿片从新岩体中穿出，先返工源，不以镜头避开。所有侧背、底部、雪侧壁必须完成，并分别检查封闭/法线/自交；岩层与根部的有意埋入须记录。

材质沿用已验证mountain双位guard与顶点色机制。以53west的冷石/蓝白雪为起点，与参考的较暖高光、灰蓝背坡逐面比较，不新增未经验证的材质特性。

## 4. 实际岸线与保护边界

不能把研究矩形当湖岸。例如实际最高支承：X940/Z-1960仅3.33m；X940/Z-1720约8.38m；X940/Z-1640已经是-22.47m，而X900/Z-1640仍有43.69m。右岸边界必须逐三角取得，不能统一延到X940。

- 原692三角的水下脚、穿Y0三角及既有湖内切口保持权威，保护区内的完整原三角不改
- 新岩肩/岩裙完整XZ投影必须连续包含于当前实际干地三角并集。新底部在每条边之间也要检验埋入，不能只让端点低于地面；参考53d已有逐0.5m检查和约4m余量
- 原六tile不改；不重跑世界生成器。不碰cliff母版、三岛/七松、道路、OceanY0、原机位、天空或飞艇
- 西村12屋实际footprint与原保守X508–702/Z-2000–-1796框保留；北6设施仍用实际footprint+50m。不能为了扩肩缩掉保护区
- West新四分件及原根资源冻结，禁止新cirque改动它们的几何/碰撞/材质；相邻低根的正常空间交叠必须在实际侧背图核对，不能掩盖接缝

## 5. 散布与完整支承来源

初步研究窗内有75个北肩锚点、84个南过渡锚点，二者合并去重152项；它们是候选观察集合，不是已确认的移动数量。这里未发现属于west已修改120项的锚点，所以优先把新形体约束在能保留这些既有落位的范围。完整索引见`scatter-study-envelopes.json`。

正式雕刻前，从真实53保存状态读回当前实例transform。对新旧最高支承变化、树冠/岩石实际mesh包围体被新山切入、落在新雪/裸石上的实例逐项判断。不能只检验树根单点，也不能按矩形把所有实例迁走。保留全部不受影响的索引、旋转、尺度、颜色和自定义数据，移位仍需真实承载面及分散间距。

完整建筑支承检查必须用**全实际场景同射线**，或自动包含每个查询点的全部实际支承mesh；绝不再次只拿六tile外推到北方。53的四个错误expected已证明Ground_1_-4不可遗漏。新计划不能通过删掉这些点或放宽3cm阈值逃过检查。

## 6. 实施与验收顺序

1. 单独新目录做cirque源，现53west作为明确基底；原48、失败四山稿、west所有版本保留
2. 先出一个中等高度肩部方案，不并行铺开east/crown。后台原生重开/坐标/封闭/保护/连续水域证明后，交父跑同灯光五面
3. 五面读形后，仅临时替换cirque视觉mesh，拍原1128/1129及200m接近图，明确标未整合；当前53west真实网格和120落位一律保留
4. 若形体仍大墙/尖锥/空面/横雪带，返回源；若原始水域有新覆盖或保护面变化，直接拒绝候选
5. 源与世界临时图成立后，重新计算实际散布影响，写严格新增/修改清单，再保存独立native mesh/collision/prefab/candidate，逐项读回
6. 完整对比原1128/1129、侧背/接近、1275/1276与真实倒影，继续记录所有失败。若水下支承真的变化，必须独立重烘深度链；否则给出全世界未变与连续干地包含证据，不凭印象沿用

本方案不会解决当前大球云、极小正面船、后方粗锥群或1275码头巨斜面。那些仍在总GOAL中，后续必须实际制作，不能随本cirque局部工作被标记完成。
