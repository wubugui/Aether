# 原实际下接缝与内域腹高：有限几何阻断

结论：若保持原真实下接缝的几何身份及原外轮廓，现行内域腹面 Y560–630m 不能同时满足。没有构造候选、修改设计门或作任何原生/视觉通过声明。

## 最小反例

- 目标 `CloudSea_1_1` 三角 530 与 +Z 邻云 `CloudSea_1_2` 三角 4706 真实相交。索引从 0 开始
- 交段两端世界 XYZ 为 `(4397.824341,632.786680,4610.587745)`、`(4401.818582,633.200990,4603.325973)`
- 中点目标垂直交点为 `[632.993835,933.760525]`，邻云为 `[632.993835,725.670254]`。每个网格均恰好两个交点，因此交段确实是下表面/下表面交线。目标厚度约300.767m，失败项是腹高
- 沿交线平面法向两侧各1m，目标/邻云底高分别为 `632.704438/633.340678` 和 `633.283232/632.646992`。底面高低顺序翻转，说明这是双云并集外侧下轮廓的真实接缝，不是埋在内部的上/下交线
- 中点距实际投影并集边界约152.968967m；由距离函数的1-Lipschitz性质，整条交段距边界至少148.825077m。交段最小腹高仍超过630m约2.786680m，不能把它称为80m外缘豁免

完整三角顶点、两端与中点重心坐标、垂直交点索引、来源SHA和数值边界均在同名JSON。脚本从冻结三角重新计算，不依靠上述舍入数字。

## 实际边界与旧拓扑

边界算法先取得269条投影朝向改变的焊接边，再减去被其它三角投影内部覆盖的区间；保留210段，形成203段外环和7段内孔环。距离来自裁剪后的并集边界，并非把所有内部silhouette边叫作外缘。外环面积约1,403,190.388m²；内孔约437.401m²。全部为float64有限计算，有明确容差，不是定向舍入形式化证明。

旧目标为2582V/7746E/5164F、单连通分量、χ=0/genus1；边二邻接、绕序及顶点link检查正常，无检测到的非邻三角横向自交。四个邻云也通过这些有限检查。既有设计允许闭合20个内部空格，因此旧genus1不是独立阻断；直接复制旧拓扑则不会变成g0。

四邻均存在实际三角相交。旧5m投影重叠区域不等于锁区，本分析没有把整个投影重叠擅自锁住。

## 必须先明确的作者选择

A. 保留真实旧下接缝：需要显式、有限的锁区/设计门新定义，否则与当前内域腹高门冲突；本项不修改120m或560–630m，也不新增豁免。

B. 放开旧内接口下表面身份：允许接缝随新腹面改变，但必须重新证明受控的新三角接触、垂直区间、间隙与连续性，并明确真正零权重锁区及过渡范围。

两者均未被本报告选择。仅有50–100m过渡说明和投影定位矩形，还不足以唯一指定可执行的三维锁。
