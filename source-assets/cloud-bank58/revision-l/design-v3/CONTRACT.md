# 冻结设计契约：厚岸与四邻连接，不保旧内部下包络

## 1. 明确取舍与优先级

原目标是厚而连贯的一整块云岸、二维错位冠肩、有底宽谷和真实四邻连接。旧v1把内部接口外侧及下缘一并精确保留，属于作者自设约束。build-v1已证这会把内部下腹锁在Y632.786680–633.200990，与原Y560–630要求冲突。

本次正式选择B，**释放选中云全部内部旧表面和旧接缝的几何身份**。包括530×4706真实下/下交段：它以后可以消失、移动，或变成并集内部埋藏交线；不能再声称“旧下接缝保留”。邻云不动。该交段仍距真正外岸>80m，不改名外缘，不增例外，不把原失败改成通过。

权威次序：用户/GOAL → 本v3锁集与接触语义 → 原v2两剖面和共享节点 → v1剩余形态、光材及观察约束。v1原collar_rule和“控制在旧四接口处全部为零”的语句仅在本次明确范围被替代；不重写旧文件。

## 2. 真正锁什么，释放什么

令D0为冻结selected实际三角投影并集，Γ0为其外部轮廓，D为Γ0内部闭域。Γ0保留原凹湾和突出部，不能取凸包/AABB，不能用有限绿色矩形替代。

`external-rim.json`给出203段有序外环、旧源边及裁剪参数，面积约1403190.387904m²、周长5579.238788m。另7段是约437.400873m²的内部投影孔；本次选用v1已允许的有限填孔，形成D并目标g0。**只填这一个有界内部孔，不填任何外凹湾；内部孔和内部接缝永远不给80m外缘豁免。**

锁集和自由度：

1. Γ0的XZ几何身份锁定。新投影外轮廓与Γ0重合、域对称差为零是设计目标，既不平移缩放，也不扩大到邻云外侧
2. 原Γ0生成边的Y不锁；旧外壁、旧上/下表面的任何正面积片区均不作为XYZ锁面。其余24根的真实表面、变换、可见性和材质则全部锁定。这样不再把旧馒头的垂直轮廓偷偷变成新目标
3. 选中云内部 ∂S0∩(int D×R) 的三角/顶点、上下包络、四邻交线、旧孔壁全部释放。新实体必须在同一D上承担覆盖及下述接触职责，不能因释放身份而丢掉整岸
4. 容许新基线外缘Y在原绝对包围范围533.418991–1057.067322内作者造型，并连续转回主体；没有“照抄原外缘Y”的隐含等式

203段是已绑定旧算法的float64有限记录，不是形式化精确几何证明。原算法有1e−10投影/重心门、1e−4m裁剪段/端点合并门。现段接点最大残差3.8878916709e−9m原样存储，未焊接或改旧点。最终权威集合是冻结三角投影的实际外部轮廓；后续对数值含混接点/极短段用源绑定exact/adaptive谓词解决，不能拿一个任意“美术容差”磨掉凹湾。这是实现数值处理，不是本项已完成的全精确求交。

## 3. 可实施的体积、支撑和过渡集合

新云选择一个闭合定向g0体积类：每个q∈int D有一个连续占据区间[B(q),T(q)]，B<T；上下表面是约束三角化上的连续分片线性函数，边缘侧面闭壳。没有独立底板、悬挂球或重复壳。该类便于验证实体区间和接触，仍须实际topology/link/orientation/自交/float32检查，不能仅由χ代替。

d(q)只取到Γ0的XZ最短距离：

- 真外缘：d=0，只锁XZ；先作者确定新基线侧缘高度
- 外缘回转带：0<d<80m，允许收尖并向主体连续回转，不复制旧下包络
- 核心：d≥80m，B∈[560,630]且T−B≥120m，含全部内部接缝与原内部孔

原v1“向内50–100m过渡”的模糊旧接口带在此被明确替代为**真实外缘0–80m控制过渡**。80来自原核心判定，不是新苛刻阈值；原四内部接邻区不再是零权重旧表面锁。控制边缘系数为u=min(1,d/80)、w=u²(3−2u)，不与旧Y作混合。该w只是控制变化权重，新基线还须本身满足连续性/厚度。

七控制的明确支撑在JSON：C01–04为已有中心、已有半跨度的紧支撑椭圆；C05在原主/支谷160m范围内、引用同一个V2；C06作用下腹全内域，保原560..615/default585的“丰满度参数”，不是把所有腹点都设585；C07保原0..25m、70..160m肩面起伏，在原最大谷底半宽85m内归零、85..160m平滑恢复，并排除腹面及权威冠/谷节点。椭圆和谷距离权重均乘w；不是把控制做成空壳Empty。

这些变动在固定XZ上重塑高度场，肩展/谷宽不靠挪整块或挪外环实现。默认基线保原v2权威值；非默认控制态也必须绑定共享节点、遵守原参数范围，并逐态验证全套空间门。并非声称整个参数笛卡尔积已可行。失败须报告，不能自动夹紧表面制造通过。

位移度量：没有旧→新顶点一一对应，因为拓扑可变；不得伪造小顶点位移来冒称保旧表面。在相同q上，高y的旧表面只可在绝对包围范围内被替换，即ΔY∈[533.418991−y,1057.067322−y]；核心B另受560..630/120限制。XZ外域位移为0。没有另加10m/25m的旧接缝移动上限，C07的25m仅是既有起伏参数。

## 4. 四邻真实接触契约

对每个冻结Ni，O_i=π(S0)∩π(Ni)只是投影候选。真正旧连接职责定义为J_i=π(int(S0∩Ni))，即旧**正体积相交**的投影足迹。三/一/一/二个5m采样分量不是J_i的真实拓扑数目。

对所有q∈J_i，新[B,T]须与Ni至少一个真实占据区间有正长度重叠；J_i边界闭包允许零长度相切。这样不会在原已连通带内新增正面积分离裂缝。没有要求保旧交线、旧下包络切换位置、旧相交深度或旧seam-loop数量；也没有任意新增最小接触宽/面积/深度。若后续证明某个J_i连续约束真与被冻结v2冲突，必须明确上报，不能只挑过门样本或暗改剖面。

每个q都从完整三角交点、定向/奇偶规则求Ni的全部区间[l_j,u_j]，定义

`gap_i(q)=min_j(max(B(q),l_j(q))−min(T(q),u_j(q)))`。

正数是间隙、零是相切、负数是实际重叠。不能拿全体minY/maxY当一个实心区间。每邻至少存在一块非零体积交接，真实新云本身连通；新云与四邻的实体并集必须连通。分量、裂缝位置和数值不确定项要报告，不只给四个bool。

未来有限全检算法已经确定，但本项未实现：叠加旧选中/邻云/候选的三角投影边，进一步切分各面高度排序及相等线。每个凸cell内按真实crossing序得到所有区间，上下端点是仿射函数；再按max/min支配关系细分，使gap在子cell上仿射，以顶点/边极限检查全cell，组装跨cell的接触体积邻接图。垂直三角、共面/相切、几乎重合必须exact/adaptive处理，不能漏掉后称全通过。另核真实triangle-triangle交接、闭壳定向和实际float32输出。该检查允许失败或未证，不允许用局部小方形替代。

外域D不扩大，所以不得新增进入外部凹湾的对角桥。新高冠仍可能改变遮挡；接触成功不自动证明没有视觉遮挡问题，原四机位须以后照常验收。
