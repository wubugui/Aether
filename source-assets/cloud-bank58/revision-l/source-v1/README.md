# L整岸隔离作者源：实现准备v1

本包是可审查的作者源/保存/fresh-open/四个源视图管线准备。**未运行Blender、Godot、保存.blend或生成源PNG。** 必须先完成独立审查、全部GitHub插件发布及逐字节远端核回，再由父任务另行准入一次source；views也独立准入。不要把pure/AST/fixture测试当原生通过。

## 本次实际做出的有限候选

- 一块1567顶点、3130三角的闭壳；不是K伸缩、球链并集、屋顶挤出或独立底板
- 使用原203段真实非凸外岸；保凹湾，只填设计v3明确释放的内部投影孔。上下片共用同一个非重叠三角化，外环共用顶点，内域严格正厚
- A/B二维错位冠、C低返脊、D低肩；主谷/盲支谷的宽底由真实顶面顶点与两侧约52m的底肩点形成；下腹连续
- 原anchor(3958,0,3667)、world轴/scale1不变；Blender坐标=(X−3958,3667−Z,Y)
- 所有原v2 PCHIP节点及A/Abelly/V2共同身份保留。曲线到有限PL并不逐点相等，下文披露误差，不发明自动通过容差

`candidate.json`是必要的完整有限候选数据；`prepare_candidate58l.py --write`是确定性纯离线重建程序，不会启动engine。日常默认无动作。候选只供隔离原生作者制作，**contact_acceptance=false / world_acceptance=false / global_GOAL=false**；完整J_i接触求解器未实现，也未用局部见证冒充完整接触。

## 默认候选的真实纯几何检查

`candidate-preparation.json`记录：单组件、Euler2、全部顶点link单环、每边两面相反方向、正体积约290,963,717.054m³。最短边0.724936m、最小三角面积0.376988m²、最大边171.475m。3130小于原5164上限。

自交检查利用本候选的具体结构，而非泛用相交程序的模糊阈值：实际float32上下片必须具有相同XZ与拓扑；对2449条平面边的12454个AABB候选对使用自适应/必要时有理符号检查，无跨边/共线重叠；连通且统一定向的盘具有唯一规定外环。上下片内域严格正厚，且只在简单外环相遇，因此无额外自交。闭壳/link/定向/属数另检，没有只用Euler冒充流形。

核心域距离直接使用源边有理交点转成的已绑定float64外环（不以float32环代替原岸）；仍为到真正外环距离≥80m，腹560–630m、垂直厚≥120m。每个三角的真实仿射违规区域（腹<560、腹>630、厚<120）各自裁成凸多边形，再以到同一真实外环线段的凸距离上界证明该整个违规子域都在80m内。最大已测上界约77.93208m；不是按顶点或采样放行，也没有把内部缝/内部孔叫外缘。基线回转在0–45m内完成，原七控制的变化权重仍严格为0–80m smoothstep。

这是有限浮点数值几何检查，保留明确正余量和自适应符号判断，不声称对任意未来网格/全部参数组合建立形式化定理。

## 数值身份与不精确之处

`rim-source-binding.json`用相邻冻结来源边的有理交点（共线时用共同原端点）解析203接点，不任意平均焊接或删凹湾。源目录接点到该交点最大差2.155709e−9m。

实际Blender本地float32坐标的外环最大对应点误差为0.0000612993113m，RMS0.0000236194304m；对应线段Hausdorff上界同最大点误差。`pointwise_identity=false`。没有因此宣布世界“逐点外环相同”或更改v3世界合同；后续正式接触/世界阶段仍须处理这些实际误差。

`profile-approximation.json`将**实际候选三角平面**与原PCHIP相交，按全部三角边/路径节点/三次节点细分，并计算每段残差多项式端点和导数实根：

- near_A：59段，最大顶差2.487160230m，最大腹差1.197594818m
- D_A_valley_B：124段，最大顶差2.338007668m，最大腹差0.364093510m
- 两剖面全部原高度节点误差严格0；路径中非整数XZ仍明确有float32舍入

上述是有限数值极值报告，不是逐点相同或误差容差获准。没有另制数学PNG代替将来真实源图。

## 七个可编辑控制

单一`L58_EDITABLE_MASTER`网格是作者母版。隐藏、禁止选择的`L58_DERIVED_EXPORT`直接引用同一网格，明确只是派生视图；不产生第二可编辑壳。唯一必要原生模型输出为`cloud_bank58l.blend`。

- C01/C02/C03/C04：原中心/椭圆半跨度/冠高范围与默认值；每个紧支撑高度场真正移动冠肩
- C05：主谷与盲支谷共用V2，floor740默认、735–780；另保width_multiplier默认1、0.9–1.1，通过固定XZ的肩面高度场改变谷宽，不能平移外岸
- C06：fullness585默认、560–615；只是下腹变化参数，不把全部下腹变成一个平面
- C07：amplitude18默认、0–25，波长125/140/160m的确定性肩部变化；谷线85m内与权威节点严格零，排除腹面

已纯测七主状态1010/1045/930/850/745/586/20，分别实际改变122/99/61/43/231/681/469顶点；C05宽1.05改变105顶点。只认这些实测状态。C06=560虽在参数范围内，但违反当前实体核心门，因此拒绝；**不夹紧、不谎称整个参数笛卡尔积都可行**。

原生文件包含完整candidate、bindings、编辑器和检查源码、拓扑源码、README。更改七个控制物件的custom value（C05还有width_multiplier），显式运行`EDIT58L.py`才重建；无handlers/auto-run/自动保存/导出。支持在固定XZ/拓扑下手工改顶点高度；重建保手工offset且不累计控制位移。无效编辑在写RNA前被拒绝。原生过程会实测八个控制状态、手工+0.125m、组合控制和完整身份恢复。
