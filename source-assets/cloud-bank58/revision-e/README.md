# E：两个极小云冠布局，仅脚本准备

这两个全新布局用于先看真实大形，再决定是否值得连接成连续外壳。
当前尚未执行生成器，没有 E 的 `.blend`、PNG 或视觉结论。
所有米制大小、位置和比例均为设计假设，不是由 1216 屏幕像素测出的
真实三维尺寸。继承的是已记录的世界坐标系、相机和中性照明参数，
没有读取、压扁或改造 D 的 325 点控制笼。

## 分件构成

每个候选只有四个独立可编辑封闭低多边形体块，预计每块 47 点／90 三角，
每候选 188 点／360 三角。每块由五个不等截面及两端封口构成，截面使用
不规则九边形轮廓；横向深度、冠部、侧移和下腹随截面变化。体块各自含
冠、肩、腹部，不在统一基盘上另加圆帽，也不使用球体、光滑细分或噪声。
候选之间的分件相交是明确的布局研究，不声称已经成为单壳连续云体。

**A：错肩短冠**

- 主冠：名义 310×255×215 m，中心局部 U/V/Y=(-30,15,795)
- 较大左肩：210×205×205 m，中心 (-180,-15,710)
- 较小右肩：195×180×195 m，中心 (145,30,690)
- 单侧低折返：170×160×175 m，中心 (95,-105,635)

意图是让两肩在不同高度和前后位置进入主冠，形成两段转向的低鞍；
低折返仅接一侧，不充当整个布局的共同底盘。是否实际读成云冠而非
几个石块，必须由新图判断。

**B：错层双冠**

- 较大主冠：300×250×220 m，中心 (-95,5,790)
- 较小后冠：220×200×190 m，中心 (140,90,755)
- 宽低鞍：215×225×190 m，中心 (35,45,685)
- 低前肩：230×185×175 m，中心 (65,-115,655)

意图是用宽鞍和前后错位打断单峰长坡，使两冠之间形成转折谷段。
该连接尚未做布尔融合，不能把体块外包盒交叠当实体连续性证明。
名义尺寸是截面缩放量，含两端延伸后的实际外包尺寸会在原生源里变化。

## 四张图与公平比较

每候选保存两个相机：真实 1216 前机位，以及两候选共同的侧后机位。
共同侧后机位只按两个候选全部顶点的共同包络计算一次，之后两源使用
相同位置、Euler 旋转和正交尺度；不为某一候选单独重取角度或放大。
前图 836×471、像素比 942/941；侧后图 836×586、至少 7% 实际顶点留边。

沿用已冻结中性材质、固定世界与太阳、Standard 色彩转换，CPU2、
8 samples、关闭去噪。每张图新进程读取保存源并直接输出 PNG，
不再存源、不新增后处理、不导出 GLB。前机位是否裁切须按实际顶点记录。

## 只做本阶段必要检查

- 保存源非空且分件名、数量和原生 float32 顶点／面与本候选脚本一致
- 每分件边恰好两面引用，全部直接可编辑、平面着色、无 modifier
- 四个实体有效可见；固定材质／灯光一致，无图像或外部库
- 每图实际相机和保存身份一致，两个侧后机位矩阵／投影相同
- 原 D/C 冻源、实图和当前输入 SHA 保持；每进程及 wrapper 实际退出保留

不做最终分件互相穿插判定、单壳证明、连续谷面证明或飞行路线验收。
这些只在视觉选形后，对选中方案的后续连续外壳开展。

## 文件、执行门与预计资源

- `layouts58e.py`：全部布局参数和小体块构造；只定义函数，不写资产
- `build58e.py`：一次生成两个压缩独立 `.blend`，每个暂估低于 200 KB
- `render_one58e.py`：每次新进程核身份并渲染一张真实图
- `run_layouts58e.py`：两个源加四图，总 90 秒／CPU2／1.5 GiB；失败即停

体积预估不是保证。任一源超过 1 MiB 会保留并停下报告，不删除编辑数据。
四个 PNG 参考 D 实测，预计总计约 1.5–2.5 MB，原样发布，实际字节数再报告。

等待父任务确认 D 失败项完整发布并安排窗口，才运行：
