# 52h B 控制笼草图数据：先审轮廓与体块关系

已实际查看失败52h正/侧/背/顶/底五图，以及ref/1216.png。原方案虽然换成多面体起形，却仍用了统一低底壳与屋顶高度场；两个高区加贯通低线，实际自然变成山丘、鞋底和U形槽。这次取消该拓扑组织。

本目录当前只有三维控制笼设计、三个原生可编辑笼和工程投影，没有合并成品、GLB、真实渲染或世界修改。旧52h与52g失败均保留。工程投影用于读坐标/轮廓，不替代实际五面源渲染。

## 三层控制点如何读

M为主块。M10/M11/M12/M13/M14组成倾斜且不共面的宽冠区，最高355m；冠区横跨约210×207m，几个高点相差35m，避免一根尖峰。M0–M4与M5–M9组成不等宽的前后折肩，保留参考里中等尺度的面向变化，不能被一轮全局光滑抹成椭球。

S为偏后侧的中肩。S8/S9/S10/S11形成275/250/235/245m的错高角面，向右后侧转出。S0/S1/S7深入主块，连接处宽，不另用窄桥；S2–S6决定外轮廓。它从主块侧向伸出，不与主块平行排成另一条长山脊。

T为偏前侧的低小肩。T6/T7/T8为200/180/160m的下落折肩，宽约110m；T3/T4提供偏斜外缘。它是贴在主块斜面的低折肩，不能平滑成第三颗球。它与S朝向不同，且体量不到S的一半。

腹部由各体自己的空间面构成：M15最低-30m，S12最低20m，T9最低15m。其余腹点错高并收向体内，没有贯穿所有部件的一圈等高底边，也没有共用底盘。

## 负空间与圆钝过渡

不绘制贯穿主冠的谷轴，不施加Gaussian低带，不用负椭球切坑。中肩和低肩向两个方向伸出后，在外侧自然留下一个短、弯、向右开放的轮廓缺口；缺口后方仍由主块实体占据，不能切穿成纵向槽。后续合并时只允许正体积融合。

后续只在实际尖锐转折处试10–18m圆钝带，优先保留宽面中心和80–180m级肩部。不使用30m全边倒角后再大范围光滑，不沿同一轴重采样等间距截面，也不先进行全件QuadriFlow后才判断轮廓。先看裸笼形态/中尺度角面，必要的均匀三角化在轮廓接受后处理。

参考仍要求云冠而非岩峰。以上数据只把上一轮明确失败的平底、双长条和直槽去掉；它仍可能显得块硬或分件感太重，需要实际源内小预览检验。当前没有把方案或工程投影标为视觉通过。
