# form-v3 四原机位独立视觉复核

审查时间：2026-10-02 23:31 UTC。

## 结论

**视觉仍不接受。form-v3 有真实、可见的局部改善，但尚未解决大冠—肩—腹的块面组织问题，且近景局部台柱感更强。不能把本轮概括为全面退步，也不能因肩峰增加而升级为美术通过。**

已直接查看本次四张原 PNG、form-v2 同名四图及 `ref/1216.png`，不是依据作者文字、验证报告或缩略图给结论。01/02 原相机及解码像素相同，因此本项是四个命名输出、三个独立视图，不算四个独立方向。

当前结论只评价已看到的隔离实体及同机位变化。灰蓝背景、没有世界云海、CPU 8 samples 的噪点，以及低多边形面本身，都不是打回原因；也没有把尚未出现的世界天气、接触和全参考构图当成本次隔离形体的失败证据。即使将这些条件排除，已见实体仍有明确造型差距。

## 逐图独立判断

### 01-original61-front 与 02-k-trial-front

- **改善成立：** form-v2 近肩连成的大整坡，在 form-v3 中出现更明确的前肩峰和后侧小隆起，前后高低与浅鞍更容易辨认；不再只是把前冠脚下连成一张连续斜面。这是真实轮廓/明暗结构变化，不是噪点造成。
- **仍未解决：** 近肩升起的峰部下方依然接很宽的斜切整面，右侧桥接/腹缘还是长的大三角带和硬转折；小体块与大冠之间的尺度层次刚刚出现，尚不足以改变整体的尖肩、台块和岩山读感。
- **局部得失：** 前肩顶部更有高低关系，但更高、更尖的肩峰并不等于更丰满的云团。不能据此前视图单独接受整个资产。

### 03-k-fixed-side-back

- **改善成立：** 右后小冠更独立，中央前方肩部较 form-v2 的宽平平台更有抬起、落下与前后叠压；外轮廓的高低节奏增加，原平台的一部分连续性确实被打断。
- **关键问题保留：** 中央大冠下方的长直立暗壁仍然支配阅读，数条细长近竖向面直接从冠部/肩线拖向下方；前右肩仍有大面积近单片暗面，前左靠近画面边缘的腹面仍是长直切面。新肩峰主要改变上缘，未让整段侧腹形成与之对应的丰满回转。
- **不能用明暗掩盖判断：** 暗色本身不是问题，参考也有深暗腹部；这里的问题是暗部背后可见的长、直、少转折的体块边界。调整背景或噪点不会自动消除这个读感。

### 04-k-fixed-near

- **改善成立：** form-v2 背景大冠之前的一张大整坡，在 form-v3 中被抬起的近肩冠和浅鞍部分拆开；近肩与后方主冠的高度关系现在更清楚。
- **局部退步/代价：** 近肩抬高后出现很醒目的横向顶缘与宽大前表面，读起来更像台柱/台块。上部峰肩分开了，但下方仍是一大片几乎不被中小体块打断的面；原“大整坡”问题更像转成“大台柱面”，未真正解除。
- **接受判断：** 这张近景最清楚地说明“新增几个峰”与“整个肩腹成为有层次的团块”仍有距离。近景不接受，且不能由 01/02 的局部改善覆盖。

## 与 ref/1216 的形体关系

参考中的近、中景云体同样是克制分面，不要求光滑球体或无锐边。其可见特点是大团上/旁附着不等大的中小团，冠、肩、暗腹不断转向、互相遮挡，亮暗界与轮廓由这些体块共同分段，大小层次并不只存在于顶部轮廓。

本次确实向“更多不等高肩冠”前进一步，但大团下方仍大量保留完整的斜坡、长直壁及台面式连接。与参考的主要差距是体块尺度与转折分布，不能以“已经低多边形”“已经有多个峰”或诊断链成功取代这项判断。参考是世界构图图，本次未渲染其世界条件；因此不宣称已完成或否定未见的全世界视觉效果。
